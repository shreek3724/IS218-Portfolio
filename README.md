## Local development

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

GitHub Pages deploys automatically from the `main` branch through GitHub Actions. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.
